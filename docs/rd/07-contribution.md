# Contribution

À compléter à partir des résultats. Pistes de contribution attendues par rapport à l'état de l'art :
- **Identité stable** des objets au-dessus d'une API à identifiants positionnels (V1).
- **Écritures sûres** en présence d'autres écrivains sur une configuration non transactionnelle (V2).
- **Application regroupée** par domaine dans un moteur déclaratif (V3).
- **Oracle de non-régression** sur `config.xml` entre deux implémentations (V5).
- **Amorçage d'une clé API** sans secret humain (V7).
- **Traduction contrôlée** d'options DHCP entre ISC et Kea (V8).
