# Haute disponibilité (CARP)

## 1. Objectif

Appliquer la configuration sur une paire `gateway` / `gateway-backup` sans dérive entre nœuds.

## 2. Prérequis

Synchronisation XMLRPC configurée entre les nœuds.

## 3. Pillar

`pfsense:restapi:settings:ha_sync: False` (valeur par défaut) : la synchronisation HA de pfrest n'est pas utilisée.

## 4. SLS

Le même highstate s'applique aux deux nœuds ; les modules lancent `rc.filter_synchronize` après leurs écritures, comme avant.

## 5. Commande

`salt -L 'gateway.<site>,gateway-backup.<site>' state.highstate test=True --batch 1`

## 6. Sortie attendue en test=True

Mêmes changements prévus sur les deux nœuds.

## 7. Vérification

Diff des deux `config.xml` avec `tests/oracle/diff_config.py` : aucun écart hors registre.

## 8. Retour arrière

Recette 44 sur les deux nœuds.

## 9. Pièges connus

- **Clé API par nœud.** La synchronisation HA de pfrest exige `page-all`, d'où le choix d'amorcer chaque nœud séparément.
